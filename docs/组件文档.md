# 知新 Zenew · 组件文档

> 全部组件从 `src/ui` 统一导出：`import { Button, Card, EmptyState } from '../ui'`
> 组件实现位置见「源码」列；样式由 `src/index.css` 的 token 驱动，**不要在页面里写颜色 / 间距魔法值**。

## 用法示例

### 1. 带三态的数据区

```tsx
import { Card, EmptyState, ErrorState, LoadingState, useAsync } from '../ui'

const { data, loading, error, reload } = useAsync(async () => {
  const db = await getDb()
  return db.select<Row[]>('SELECT * FROM card ORDER BY id DESC')
}, [])

if (loading) return <LoadingState rows={3} title="正在读取卡片" />
if (error) return <ErrorState desc={error} onRetry={reload} />
if (!data?.length) return (
  <EmptyState
    title="还没有卡片"
    desc="导入教材 PDF 或生成大纲后，这里会出现可复习的卡片。"
    action={<Button variant="primary" onClick={() => nav('/courses')}>去创建课程</Button>}
  />
)
```

### 2. 表单（错误态 + 防重复提交）

```tsx
const [busy, run] = useSubmit()
const [name, setName] = useState('')
const [err, setErr] = useState('')

<Input label="词书名称" required value={name} error={err} hint="最多 10 个字"
       onChange={(e) => { setName(e.target.value); setErr('') }} />
<Button variant="primary" loading={busy} onClick={() => run(async () => {
  if (!name.trim()) return setErr('请填写名称')
  await save(name)
  toast.success('已保存')
})}>保存词书</Button>
```

### 3. 危险操作二次确认

```tsx
const [confirm, setConfirm] = useState<Row | null>(null)

<Button variant="danger" size="sm" onClick={() => setConfirm(row)}>删除课程</Button>

<ConfirmDialog
  open={!!confirm}
  danger
  title={`删除课程「${confirm?.name ?? ''}」？`}
  description="该课程下的知识点、卡片与学习记录都会一并删除，且无法恢复。"
  confirmText="确认删除"
  loading={busy}
  onCancel={() => setConfirm(null)}
  onConfirm={() => run(async () => { await remove(confirm!.id); setConfirm(null); toast.success('已删除') })}
/>
```

### 4. 表格（高信息密度）

```tsx
<DataTable
  caption="第 3 章 · 知识点覆盖情况"
  rows={topics}
  rowKey={(t) => t.id}
  defaultSort={{ key: 'cards', dir: 'desc' }}
  columns={[
    { key: 'title', header: '知识点', sortable: true },
    { key: 'cards', header: '卡片', align: 'end', sortable: true },
    { key: 'mastered', header: '已掌握', align: 'end', sortable: true },
    { key: 'ops', header: '操作', align: 'end', render: (t) => (
        <Button size="xs" variant="outline" onClick={() => gen(t.id)}>生成</Button>
      ) },
  ]}
  empty={<EmptyState title="本章还没有知识点" desc="导入教材或生成大纲后自动出现。" />}
/>
```

### 5. 主题与语言

```tsx
const { mode, resolved, setMode, toggle } = useTheme()   // system | light | dark
const { t, lang, setLang } = useI18n()
<IconButton label={resolved === 'dark' ? '切换到浅色' : '切换到深色'} onClick={toggle}>
  {resolved === 'dark' ? <Sun size={17} /> : <Moon size={17} />}
</IconButton>
```

```tsx
/>
```
