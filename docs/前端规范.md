# 知新 Zenew · 前端规范（Sky v5）

> 适用范围：`Zenew/app`（React 19 + Vite + TypeScript + Tauri）。
> 所有数值以设计 token 为准（`src/index.css` 的 `:root`），**页面里不写魔法数字**。

---

## 一、设计 token

### 1.1 色彩

| 语义 | Token | 浅色 | 深色 |
|---|---|---|---|
| 品牌主色 | `--brand`(`--brand-500`) | `#245EF0` | `#6E9BFF` |
| 品牌色阶 | `--brand-50/100/200/300/400/500/600/700` | 浅→深 | 深→浅（自动反转） |
| 成功 | `--success-500` / `--success-wash` / `--success-ink` | `#2AA391` | `#5FD0BC` |
| 警告 | `--warning-500` / `--warning-wash` / `--warning-ink` | `#FFB020` | `#FFC46B` |
| 危险 | `--danger-500` / `--danger-wash` / `--danger-ink` | `#E4574C` | `#FF8F86` |
| 信息 | `--info-500` / `--info-wash` | 同品牌色 | 同品牌色 |
| 正文 | `--ink` | `#162D36`（≈13:1） | `#E9F1FB` |
| 次级文字 | `--ink-2` | `#4E6577`（≈6:1） | `#A9BED6` |
| 弱化文字 | `--ink-3` | `#6B7F92`（≈4.6:1，达 AA） | `#8AA1BC` |
| 卡面 | `--card` / `--card-glass` | `#FFFFFF` / 半透明白 | `#16263F` |
| 分隔线 | `--line` / `--line-strong` | `#E2ECF8` / `#CFE0F3` | 白色 9% / 16% |
| 遮罩 | `--mask` | `rgba(18,36,74,.34)` | `rgba(4,10,22,.62)` |

**规则**：同一语义全站同色；不要在页面里写死 hex；正文/按钮对比度必须 ≥ 4.5:1（大字 ≥ 3:1）。

### 1.2 间距（4px 基准）

`--sp-1: 4` · `--sp-2: 8` · `--sp-3: 12` · `--sp-4: 16` · `--sp-5: 20` · `--sp-6: 24` · `--sp-7: 32` · `--sp-8: 40` · `--sp-9: 56` · `--sp-10: 80`

区块之间用 `--sp-4/5`，卡片内边距 `--sp-4`，行内元素间距 `--sp-2`。

### 1.3 字号（rem，随 `--scale` 缩放，支持长辈版/系统放大）

`--fs-2xs(.66)` `--fs-xs(.72)` `--fs-sm(.8)` `--fs-base(.94)` `--fs-md(1)` `--fs-lg(1.08)` `--fs-xl(1.24)` `--fs-2xl(1.55)` `--fs-3xl(2)` `--fs-4xl(2.6)`
字重：`--fw-regular(400)` `--fw-medium(500)` `--fw-semibold(600)` `--fw-bold(750)` `--fw-black(850)`
行高：`--lh-tight(1.25)` `--lh-base(1.6)` `--lh-loose(1.8)`
字体族：`--font`（Inter + MiSans/HarmonyOS/微软雅黑/PingFang 兜底）、`--mono`

### 1.4 圆角 / 阴影 / 动效 / 布局

| 类别 | Token |
|---|---|
| 圆角 | `--r-chip(8)` `--r-input(12)` `--r-btn(12)` `--r-card(20)` `--r-modal(24)` `--r-pill(999)` |
| 阴影 | `--elev-1`（卡片）`--elev-2`（浮层/导航坞）`--elev-3`（弹窗/抽屉） |
| 动效时长 | `--dur-fast(120ms)` `--dur-base(200ms)` `--dur-slow(320ms)` |
| 缓动 | `--ease`（通用）`--ease-out`（入场）`--ease-spring`（弹跳） |
| 布局 | `--container(880px→960px 宽屏)` `--appbar-h` `--tabbar-h` `--scale` |

## 二、栅格与响应式

- 内容列：`.appinner` 使用 `--container`；宽屏 1440+ 提升到 960px，平板 ≤1024 收边距，手机 ≤720 收边距并切换底部导航形态。
- 12 列栅格工具：`.grid-12` + `.col-4/.col-6/.col-8/.col-12`（≤1024 自动堆叠）。
- 断点：**桌面 >1024 / 平板 721–1024 / 手机 ≤720**（另含 ≤420 兜底、≥1440 超宽）。
- 固定元素：顶栏与底部导航坞为固定层；内容区独立滚动（`.appbody`），滚动时顶栏不移动。
- 留白节奏：区块间距 `--sp-4`；卡片内 `--sp-4`；标题与内容 `--sp-2`。

---

## 三、组件使用规范

统一从 `src/ui` 引入（`import { Button, Card, EmptyState } from '../ui'`）。

- **按钮**：一个视图最多一个主按钮（`variant="primary"`）；危险操作 `variant="danger"`；异步提交必须传 `loading`（自带禁用与 spinner，防重复提交）。
- **表单**：`Input/Textarea` 自带 label/hint/error 与 `aria-invalid`；错误态用 `error` 属性而不是改颜色；开关必须给 `label`。
- **三态**：任何数据区必须覆盖 `loading`（骨架屏）/ `empty`（文案 + 行动按钮）/ `error`（重试）。
- **反馈**：操作结果用 `useToast()`（成功/失败/提示），不要自己造 toast。
- **危险确认**：删除、清空、退出登录等用 `ConfirmDialog`，不要用 `window.confirm`。
- **可达性**：图标按钮一律用 `IconButton label="..."`；自定义可点击容器需 `role`/`tabIndex`/键盘事件；状态不要只靠颜色（配图标或文字）。
- **文案**：按钮＝动词＋对象（「保存计划」「删除课程」）；错误＝说人话＋给解法（「服务暂时不可用，请稍后重试」）。

## 四、状态与异常覆盖清单

| 场景 | 做法 |
|---|---|
| 加载 | `<LoadingState rows={3} />` 或 `Skeleton`（固定高度，避免布局抖动） |
| 空 | `<EmptyState title desc action />`（行动按钮指向下一步） |
| 错误 | `<ErrorState desc onRetry />`；页面级异常由 `ErrorBoundary` 兜底 |
| 成功 | `toast.success('已保存')` |
| 断网 | 全局 `NetBanner`（离线时提示本地可用 + 重连按钮） |
| 超长文本 | `.truncate` / `.clamp-2` / `.wrap-anywhere` |
| 超大数字 | `formatNumber` / `formatCompact`，表格数字列用 `.tnum`（等宽对齐） |
| 极端窗口 | 最小宽度 960（Tauri 配置）；≤420 兜底样式；超宽内容居中不拉伸 |

## 五、可访问性（AA）

- 键盘：全部功能可用 Tab 到达，`Enter/Space` 激活；`Tabs` 支持 ← →/Home/End；复习页支持 `1-4` 作答、`空格` 翻面、`Esc` 退出。
- 焦点：`:focus-visible` 统一 2px 品牌色描边 + 2px 偏移；弹窗/抽屉用 `useFocusTrap` 锁焦点并在关闭后归还。
- 语义：`role="tablist/tab"`、`role="switch"`、`role="dialog" aria-modal`、`role="progressbar"`、`aria-live`（Toast/网络提示/开关状态）、`aria-current="page"`（导航）。
- 对比度：正文 ≥7:1、次级 ≥6:1、弱化 ≥4.6:1；深色主题同等校验。
- 非颜色区分：状态标签带图标（✓/⚠/✕），正确/错误选项带勾叉。
- 可缩放：字号均为 rem，`--scale` 由「显示设置/长辈版/系统字号」驱动，放大后不破版。

---

## 六、动效

- 时长只用 `--dur-*`；入场用 `--ease-out`，强调用 `--ease-spring`。
- 允许的动效：页面进场（`.page-in`）、列表增删（`.fade-up`）、展开收起、弹窗/抽屉（Modal/Drawer 内置）、纸屑庆祝（仅答对）、词云漂浮。
- `prefers-reduced-motion: reduce` 时全部动画降到 0.01ms 且关闭装饰光斑（已实现，勿绕过）。

---

## 七、主题与多端

- 主题：`ThemeProvider` 写 `html[data-theme=light|dark]`，支持「跟随系统 / 浅色 / 深色」，并同步 `color-scheme` 让原生滚动条与表单控件跟随。
- 平台差异：`TitleBar` 按平台放置窗口按钮（Windows/Linux 右侧，macOS 左侧留位）。
- 高 DPI：图标统一 svg + 尺寸 token（16/20/24），不用位图图标；1px 线用 token 颜色而非半像素 hack。

---

## 八、性能

- 首屏：`AuthGate` 先渲染准备态，页面用骨架屏；避免白屏。
- 长列表：`Pagination`（页码）或 `LoadMore`（加载更多），表格用 `DataTable`（表头吸顶）。
- 资源：目前无位图资源（媒体卡为 CSS 渐变 + 字形），无需懒加载；如后续引入图片，使用 `loading="lazy"` + 固定宽高占位。
- 交互：输入 → 状态即时反馈；搜索类输入用 `useDebounced`；提交类用 `useSubmit`（并发点击直接忽略）。
