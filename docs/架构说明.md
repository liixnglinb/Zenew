# 架构说明（给后续接手者）

> 上次校准：2026-10-06，对应 v0.22.0。产品事实以 `README.md` 与仓库根外的《知新Zenew-产品信息.md》为准；本文只讲「代码怎么组织、数据怎么流、改哪里怎么扩」。

## 1. 目录结构

```
app/
  src/
    main.tsx        入口：全局 error/unhandledrejection 兜底 + createRoot
    App.tsx         BootGate（本地库初始化）→ Shell（标题栏/侧栏/路由）
    index.css       设计令牌唯一来源（:root + [data-theme=dark]），组件规则全在这里
    desktop.css     桌面层覆盖（左侧导航外壳、多栏、快捷键、右键菜单）；加载次序 index → desktop → 各页 css
    db.ts           SQLite 封装：isTauri 守卫、ensureSchema（建表+迁移）、getDb
    fsrs.ts         FSRS 调度封装（ts-fsrs）；schedule/cardToRow/rowToCard/isMastered
    study.ts        学习域逻辑：设置、音效、 streak、任务、词根词缀、形近词、四选一
    train.ts        五种训练模式的状态机与听写设置；speakWord（speechSynthesis）
    vocab.ts        词书与查词：public/dict/*.json 同源懒加载 → course/topic/card 落库
    emblem.ts       程序化形义徽标（词 → 确定性渐变/纹样）
    api.ts ❌       v0.22.0 已删除（无账号无云端）
    pages/          14 个页面，全部只用 src/ui 组件库
    ui/             组件库：primitives/forms/overlays/feedback/navigation/sidebar/toast/theme
  src-tauri/        Rust 壳：窗口、托盘、关到托盘、单实例、deep-link、updater
  public/dict/      内置词库（index.json + 四书，8.5MB，构建时原样拷进 dist）
  tests/core.test.ts  单测（npm test）
server/ server-worker/   早期云端网关，v0.22.0 起无客户端消费者，保留备查
scripts/            发版与验收脚本（见下「发版链」）
```

## 2. 数据流（单向）

```
用户操作 → 页面事件 → study/train/vocab 的领域函数
        → db.ts（tauri-plugin-sql → SQLite，落 %APPDATA%/Roaming/com.zenew.app/zenew.db）
        → React state（页面内 useState；跨页徽标用 refreshBadges 回调）
```

- **词书数据**：`vocab.loadBook(file)` fetch 同源 `/dict/<file>`（懒加载+失败重试）→ `importVocabRange` 落 course(kind='vocab')/topic/card 三表 → 复习走统一 FSRS 队列。**改词库内容 = 换 public/dict 的 JSON**，不要动表结构。
- **调度**：所有评分（主复习 + 训练）都走 `fsrs.schedule(row, grade)` 单入口，落 `card_state` + `review_log`。改调度只改这一个文件。
- **设置**：localStorage（`zenew_settings_v1` / `zenew_dictation`），读侧全部「坏数据回落默认」；显示类经 `applySettings` 写 CSS 变量。

## 3. 关键决策（为什么是这样）

| 决策 | 原因 |
|---|---|
| 无账号、无云端（v0.22.0 删 `api.ts`/`Login.tsx`） | 生成功能已移除，账号闸门失去保护对象；本地数据本就不经服务器 |
| 词库内置进安装包 | 查词/导入/形近词全部离线可用；代价是安装包 4.6→7MB |
| 设计令牌只重定向取值、保留变量名 | Win11 改版不动 1800 行组件规则；回滚=还原 `:root` 一段 |
| 数据库「只过滤不删除」 | v0.17.0 砍课程体系时旧数据行保留，靠 SQL 侧 `kind='vocab' AND type='word'` 过滤；**勿以「库里还有行」为由恢复课程功能** |
| 关闭=隐藏到托盘 | 桌面习惯；`lib.rs` CloseRequested 拦截 + 托盘单击恢复 |
| 单实例 + zenew:// 深链 | 二次启动转发到已运行窗口（`tauri-plugin-single-instance`） |

## 4. 扩展点

- **加词书**：`vocab.ts` 的 `WORD_BOOKS` 加一项 + `public/dict/<file>.json`（字段：w/uk/us/m/s/r）+ 各页 `COVERS` 配色（Today/Plan/Vocab 三处同款，改一处要同步注释里声明的另一处）。
- **加训练模式**：`train.ts` 的 `TrainMode`/`TRAIN_MODES`/`MODE_META` + `pages/Train.tsx` 分支 + `WordList.tsx` 的 `TRAIN_ITEMS`。
- **改视觉**：只动 `index.css` 的令牌段；注意 `desktop.css` 是后加载覆盖层，能整段改回 `:root` 值（先查加载次序）。
- **恢复账号/付费**：从 git 历史（v0.21.0 及更早）找回 api.ts/Login.tsx；别恢复已下线的购买页（站点 301 已固化）。

## 5. 发版链（浓缩版，详细踩坑见仓库外《Voyra个人网站说明.md》§5.6）

版本源 `app/src-tauri/tauri.conf.json` → `npm run lint && npm test && npm run build` → `npm run tauri build`（签名步骤报无私钥属预期，exe 已产出）→ Git Bash 手动签名（别用 cmd 包装）→ `node scripts/verify-signature.mjs` 回验 → `gh release upload --clobber` → 三件套同步站点 `public/zenew/dl/` → 真机 CDP 验收（`WEBVIEW2_ADDITIONAL_BROWSER_ARGUMENTS=--remote-debugging-port=9222` + `node scripts/cdp-verify-v022.mjs`，22 项断言）。

**红线**：`.tauri/zenew.key` 与 `.secrets/` 严禁入库；NSIS 钩子别碰 `$0-$9`（会静默装空包）；push 失败按 §11.1 对策，不硬冲。
